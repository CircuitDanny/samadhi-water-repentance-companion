# Downloadable resources

These are the expanded September 2026 A4 editions for printing or offline reading. The six English resources and bilingual master are generated from the aligned source chapters.

| File | What it contains |
|---|---|
| [01 - Scroll One Practice Companion](01-scroll-one-practice-companion.pdf) | A 20-page guide to the opening scroll, with source-wording notes and practice cues. |
| [02 - Scroll Two Practice Companion](02-scroll-two-practice-companion.pdf) | A 16-page guide to karma, conduct, speech and the senses. |
| [03 - Scroll Three Practice Companion](03-scroll-three-practice-companion.pdf) | A 17-page guide to results, dedication and memorial practice. |
| [04 - Master Print Edition](04-master-print-edition.pdf) | The full 110-page English study resource, including core teachings and a practical beginner routine. |
| [04 - English-Vietnamese Edition](04-master-english-vietnamese-edition.pdf) | The complete 232-page master in 116 matching English and Vietnamese page pairs, with Southern Buddhist written usage and translated diagrams. |
| [05 - Buddhas and Bodhisattvas Guide](05-buddhas-and-bodhisattvas-guide.pdf) | 22 pages of illustrated profiles, stories, relationships, pronunciation and practice pathways. |
| [06 - Glossary Reference](06-glossary-reference.pdf) | 32 pages with 389 beginner-friendly entries, six-senses guidance and pronunciation support. |

For the clearest reading sequence, use files 01, 02 and 03 beside the official liturgies. Keep files 05 and 06 as quick references. File 04 is the recommended all-in-one print edition.
