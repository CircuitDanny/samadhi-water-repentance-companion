# Downloadable resources

These are the final A4 editions for printing or offline reading.

| File | What it contains |
|---|---|
| [01 - Scroll One Practice Companion](01-scroll-one-practice-companion.pdf) | A 16-page guide to the opening scroll. |
| [02 - Scroll Two Practice Companion](02-scroll-two-practice-companion.pdf) | A 14-page guide to karma, conduct, speech and the senses. |
| [03 - Scroll Three Practice Companion](03-scroll-three-practice-companion.pdf) | A 13-page guide to results, dedication and memorial practice. |
| [04 - Complete Three-Scroll Companion](04-complete-three-scroll-companion.pdf) | The full 76-page study resource in one file. |
| [05 - Buddhas and Bodhisattvas Guide](05-buddhas-and-bodhisattvas-guide.pdf) | Illustrated profiles, stories, pronunciation and practice pathways. |
| [06 - Glossary Reference](06-glossary-reference.pdf) | 375 beginner-friendly terms from all three scrolls. |

For the clearest reading sequence, use files 01, 02 and 03 beside the official liturgies. Keep files 05 and 06 as quick references. File 04 is the all-in-one edition.
